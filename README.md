# AI-Study-Planner-Agent

*Capstone Project (Google 5-Day AI Agents)*

An interactive study planning agent that generates daily/weekly study schedules based on subjects, hours available, difficulty, deadline, and current mastery level.

## Features
- Accepts user inputs (subjects, hours/day, difficulty, deadline).
- Generates daily micro-tasks, weekly plan, and revision blocks.
- Simple offline rule-based planner (works without API keys).
- Placeholder for LLM integration (Gemini / Vertex AI / OpenAI) to improve plan generation and personalization.

## Files
- study_planner_agent.ipynb — Colab notebook with full implementation and usage.
- sample_inputs.json — example input payloads.
- README.md — this file.

## How to run (beginner-friendly)
1. Open the notebook study_planner_agent.ipynb in Google Colab.
2. Run cells top-to-bottom. The notebook has a working rule-based planner that produces a plan instantly.
3. (Optional) Follow the LLM integration cell to connect Gemini / Vertex AI / OpenAI — you will only need to paste your API key.
